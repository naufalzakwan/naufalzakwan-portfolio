# Personal memory photographs

The website's photo references, captions and alt text are maintained in `src/data/memories.ts`. The orbit and story chapters share that data; preserve stable IDs and the existing entry order when editing.

The current personal images are intentionally retained. Adding or replacing an image requires updating its reference, original dimensions, alt text and any intentional object position. Keep the shared-photo handoff and responsive frame rules intact.

Before publishing or redistributing these photographs, review consent for other people shown in them. The code or third-party component licenses do not grant reuse permission for personal photographs.
